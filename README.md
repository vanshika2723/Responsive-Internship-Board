# 💼 InternBoard – Internship Opportunities

InternBoard is a modern and responsive internship opportunity board designed to help students and freshers discover suitable internships based on their skills, domain, and preferred work mode.

The project provides a clean, attractive, and user-friendly interface where users can browse internships, filter opportunities, view complete details, save internships, and submit applications.

## 📌 Features

### 🔎 Internship Search
- Search internships by role, company, domain, or skills.
- Quickly find relevant internship opportunities.

### 🎯 Smart Filters
Users can filter internships based on:

- Domain
- Work Mode
- Internship Role
- Search Keywords

Available domains include:

- Full Stack Development
- UI/UX
- Data Analytics
- Cyber Security

Work modes include:

- Remote
- Hybrid
- On-site

### 💼 Internship Cards

Each internship card displays:

- Company name
- Internship role
- Domain
- Location
- Work mode
- Stipend
- Duration
- Required skills
- Application deadline
- Available openings

### ⭐ Featured Internships

Important internship opportunities are highlighted as featured listings for easier discovery.

### ❤️ Save Internships

Users can save/bookmark internship opportunities for later.

Saved internships are stored using browser `localStorage`.

### 📄 Internship Details

Users can open an internship and view complete information including:

- Company
- Role
- Description
- Skills
- Stipend
- Duration
- Location
- Deadline
- Available openings

### 📝 Apply for Internship

Users can submit an application through the application form.

The form includes:

- Applicant Name
- Email
- Portfolio URL
- Cover Message

### ✅ Form Validation

The application form validates:

- Required fields
- Email format
- Portfolio URL
- User input errors

### 💾 Local Storage

The project uses browser `localStorage` for:

- Saved internships
- Submitted applications

No backend database is required for this demo project.

### 📱 Responsive Design

The website is responsive and works across:

- Desktop
- Laptop
- Tablet
- Mobile
